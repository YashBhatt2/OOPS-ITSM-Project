# Service Desk website

The React and TypeScript client provides employee, technician, and administrator workspaces. Vite forwards API requests to the local Spring Boot server.

See the [setup guide](../RUNNING.md) for the database and backend. From this directory, run `npm ci` and `npm run dev` to open the app at http://localhost:5173.

Run `npm test` for the frontend tests, `npm run build` for a production build, and `python3 design-tools/contrast.py --check` to check both color themes.
